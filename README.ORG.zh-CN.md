# AtomUI

AtomUI 是面向 Avalonia/.NET 桌面应用的 UI 组件体系，围绕 Ant Design 设计规范提供跨平台控件、主题能力、文档和示例项目。

我们关注的是让 .NET 开发者更稳定地构建 Windows、macOS 和 Linux 桌面软件：组件行为清晰、视觉规范一致、工程集成直接、文档可查可用。

## 项目方向

- **AtomUI OSS**：开源 UI 控件库，提供 Avalonia 桌面应用常用基础组件。
- **主题与设计规范**：围绕 Ant Design 交互和视觉体系，沉淀适用于桌面端的组件规范。
- **文档与示例**：提供安装、使用、组件 API、示例工程和常见问题说明。
- **商业组件**：在开源版本基础上，规划更复杂的业务控件和企业支持能力。

## 开发者入口

- 官网：[https://atomui.net](https://atomui.net)
- NuGet：[AtomUI.Desktop.Controls](https://www.nuget.org/packages/AtomUI.Desktop.Controls)
- 源码：请查看组织下的 AtomUI 相关仓库
- 文档：通过官网文档中心查看快速开始、组件说明和 API Reference
- 问题反馈：欢迎通过 Issue 提交 bug、使用问题和改进建议

## 适用场景

AtomUI 适合用于构建基于 Avalonia 的跨平台桌面应用，包括：

- 管理后台和业务系统客户端
- 工具软件、开发者工具和数据库客户端
- 需要统一视觉规范的企业桌面应用
- 需要同时覆盖 Windows、macOS、Linux 的 .NET 应用

## 参与贡献

我们欢迎开发者参与 AtomUI 的长期建设，包括：

- 提交问题复现和 bug report
- 改进组件行为和样式一致性

在提交 PR 前，请优先阅读对应仓库的贡献说明、代码规范和本地构建方式。

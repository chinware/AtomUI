# Data Display 控件

数据展示类桌面控件文档放在本目录，例如 List、ListView、TreeView、DataGrid、Card、Descriptions、Expander、Timeline、Tag、Statistic。

此分类关注数据结构展示、列表/树/表格行为、分组、排序、过滤、高亮和虚拟化。DataGrid 作为独立包，包级架构在 `docs/modules/desktop-controls-datagrid/`。

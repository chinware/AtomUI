# Data Entry 控件

数据录入类桌面控件文档放在本目录，例如 LineEdit、TextArea、Select、TreeSelect、DatePicker、TimePicker、ColorPicker、Upload、Form。

此分类关注用户输入、选择、校验、异步加载、过滤和上传等行为。ColorPicker 作为独立包，包级架构在 `docs/modules/desktop-controls-colorpicker/`。

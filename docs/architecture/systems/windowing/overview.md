# Windowing 系统

Windowing 系统跨越应用启动配置、`AtomUI.Desktop.Controls` 的 Window/主题和 `AtomUI.Native` 的平台能力。
本目录维护跨模块所有权、合成策略、生命周期和验证不变量；单个平台 API 仍由 Native 模块文档拥有。

- [Windows live resize 与窗口装饰](windows-live-resize.md)：Windows 合成模式、CSD 所有权和验证矩阵。
- [Window 使用指南](../../../guides/windowing/overview.md)：跨平台配置和 `WindowDrawnDecorations` 使用方式。
- [Native 模块](../../../modules/native/overview.md)：Windows、macOS、Linux 与 Wayland 平台 API。

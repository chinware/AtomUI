# AtomUI 6.1.6 API 变更示例

本文档补充 `6.1.6` 相比 `6.1.5` 的破坏性 API 变更和迁移写法。正式版本条目见仓库根目录
`CHANGELOG.md` 和 `CHANGELOG.zh-CN.md`。

使用 Avatar 图片属性或命名空间、ImagePreviewer source 契约、原 `LineEdit : TextBox` 继承关系、
直接 `OtpLineEditCell` 样式或生成式 Avatar Token API 的应用，升级前必须完成本文迁移。

英文版本：[6.1.6 API Change Examples](6.1.6-api-changes.md)。

## 快速对照

| 范围 | 6.1.5 | 6.1.6 |
|---|---|---|
| Avatar 控件命名空间 | `AtomUI.Desktop.Controls.Avatar` | `AtomUI.Controls.Avatar` |
| Avatar 基类命名空间 | `AtomUI.Controls.Commons.AbstractAvatar` | `AtomUI.Controls.AbstractAvatar` |
| Avatar 图片来源 | `Src: string?`、`BitmapSrc: IImage?` | `Source: ImageLoadSource?`、`FallbackSource`、`RequestOptions` |
| Avatar 文本变换 | 公开 `TextRenderTransform` | 内部实现；使用控件 `RenderTransform` 或自定义模板 |
| Avatar 生成式 Token 命名空间 | `AtomUI.Desktop.Controls.DesignTokens` | `AtomUI.Controls.DesignTokens` |
| Card Avatar 类型 | `CardMetaContent.Avatar: AtomUI.Desktop.Controls.Avatar?` | `CardMetaContent.Avatar: AtomUI.Controls.Avatar?` |
| 预览集合 | `Source`、`Sources`、`FallbackSource` | `ItemsSource: IEnumerable<ImagePreviewItem>?` |
| 预览 source 契约 | `IImagePreviewSource`、`UriImagePreviewSource`、`StreamImagePreviewSource` 及相关 loader 类型 | 不可变 `ImagePreviewItem` 中的 `ImageLoadSource` |
| 预览并发 | 控件级 `MaxConcurrentLoads` | 应用级 `UseImageLoading(options => ...)` |
| 预览标题解析器 | `ResolveTitle(ImagePreviewTitleResolveContext)` 和 `context.Source` | `ResolveTitle(in ImagePreviewTitleResolveContext)` 和 `context.Item` |
| 输入继承关系 | `LineEdit : AtomUI.Desktop.Controls.TextBox` | `LineEdit`、`TextBox`、`TextArea` 继承 `AbstractTextInput` |
| OTP 单元格表面 | 公开 `OtpLineEditCell` 及单元格生成式 Token | 单元格实现和 Token 表面调整为内部；配置 `OtpLineEdit` |

## Avatar 迁移

### 更新命名空间和图片来源属性

`Avatar` 现在属于基础 `AtomUI.Controls` 包和命名空间。`Src`、`BitmapSrc` 已移除，统一改用图片加载契约。
XAML 字符串仍可转换为 `ImageLoadSource`，C# 调用方应显式构造强类型来源。

#### 6.1.5 写法

```csharp
using AtomUI.Desktop.Controls;
using Avalonia.Media;

Avatar CreateRemoteAvatar()
{
    return new Avatar
    {
        Src = "https://cdn.example.com/users/alice.png"
    };
}

Avatar CreateBitmapAvatar(IImage bitmap)
{
    return new Avatar
    {
        BitmapSrc = bitmap
    };
}
```

#### 6.1.6 写法

```csharp
using AtomUI.Controls;
using Avalonia.Media;

Avatar CreateRemoteAvatar(IImage fallbackBitmap)
{
    return new Avatar
    {
        Source = ImageLoadSource.FromUri("https://cdn.example.com/users/alice.png"),
        FallbackSource = ImageLoadSource.FromImage(fallbackBitmap),
        RequestOptions = new ImageRequestOptions
        {
            Timeout = TimeSpan.FromSeconds(10),
            CachePartition = "avatars"
        }
    };
}

Avatar CreateBitmapAvatar(IImage bitmap)
{
    return new Avatar
    {
        Source = ImageLoadSource.FromImage(bitmap, cacheKey: "alice-avatar")
    };
}
```

`ImageLoadSource.FromImage` 只借用传入的 `IImage`，loader 和 Avatar 都不会销毁它。`ImageLoadSource` 还提供
URI、文件、资源、存储文件、字节和可重复打开流的来源。

### 替换仅作用于文本的 RenderTransform

`TextRenderTransform` 不再公开，因为文本适配由 Avatar 模板负责。如果希望变换整个 Avatar，可以设置控件的
`RenderTransform`：

```csharp
using Avalonia.Media;

avatar.RenderTransform = new RotateTransform(5);
```

仅变换生成式文本 presenter 不再有直接的公开替代 API。需要这种效果的应用必须提供自定义 Avatar 模板，并变换
模板中自行定义的 presenter。

### 更新生成式 Avatar Token 命名空间

生成式 Avatar Token markup extension 随控件从桌面包移至基础控件包。使用 AtomUI 共享
`https://atomui.net` XML 命名空间的应用通常不需要修改 AXAML；显式 CLR 命名空间映射必须更新。

#### 6.1.5 写法

```xml
<UserControl
    xmlns:avatarTokens="clr-namespace:AtomUI.Desktop.Controls.DesignTokens;assembly=AtomUI.Desktop.Controls">
    <Border Width="{avatarTokens:AvatarTokenResource ContainerSize}" />
</UserControl>
```

#### 6.1.6 写法

```xml
<UserControl
    xmlns:avatarTokens="clr-namespace:AtomUI.Controls.DesignTokens;assembly=AtomUI.Controls">
    <Border Width="{avatarTokens:AvatarTokenResource ContainerSize}" />
</UserControl>
```

### 更新 `CardMetaContent.Avatar` 类型引用

属性名没有变化，但其 CLR 类型现在来自 `AtomUI.Controls`。

#### 6.1.5 写法

```csharp
using AtomUI.Desktop.Controls;

var content = new CardMetaContent
{
    Avatar = new Avatar { Text = "A" }
};
```

#### 6.1.6 写法

```csharp
using AtomUI.Controls;
using AtomUI.Desktop.Controls;

var content = new CardMetaContent
{
    Avatar = new Avatar { Text = "A" }
};
```

## ImagePreviewer 迁移

### 以 `ItemsSource` 替代 `Source` 和 `Sources`

ImagePreviewer 不再维护独立的图片 source 和 loader 模型。每一项现在是公开的不可变 record，其中包含统一图片来源，
以及可选的缩略图、回退来源、请求选项、标题和应用 Tag。

#### 6.1.5 写法

```csharp
var previewer = new ImagePreviewer
{
    Source = new UriImagePreviewSource("https://cdn.example.com/images/cover.png"),
    Sources =
    [
        new UriImagePreviewSource("https://cdn.example.com/images/one.png"),
        new UriImagePreviewSource("https://cdn.example.com/images/two.png")
    ],
    FallbackSource = new UriImagePreviewSource("avares://Acme.App/Assets/fallback.png"),
    MaxConcurrentLoads = 4
};
```

#### 6.1.6 写法

```csharp
using AtomUI.Controls;
using AtomUI.Desktop.Controls;

var fallback = ImageLoadSource.FromAsset(
    new Uri("avares://Acme.App/Assets/fallback.png"));

var previewer = new ImagePreviewer
{
    ItemsSource =
    [
        new ImagePreviewItem(
            ImageLoadSource.FromUri("https://cdn.example.com/images/one.png"))
        {
            ThumbnailSource = ImageLoadSource.FromUri(
                "https://cdn.example.com/images/thumbnails/one.png"),
            FallbackSource = fallback,
            Title = "One"
        },
        new ImagePreviewItem(
            ImageLoadSource.FromUri("https://cdn.example.com/images/two.png"))
        {
            FallbackSource = fallback,
            Title = "Two"
        }
    ]
};
```

单图预览时，向 `ItemsSource` 提供只包含一个 `ImagePreviewItem` 的集合。仍可使用 `CurrentIndex` 和
`CoverIndex` 选择当前预览项和封面项。

### 替换自定义流来源

`IImagePreviewSource`、`IImagePreviewSourceIdentity`、`UriImagePreviewSource`、`StreamImagePreviewSource`、
`ImageSourceUri`、`IImageSourceLoader`、`DefaultImageSourceLoader`、`LoadedImageSource` 和
`ImagePreviewItemState` 已移除。请改用相应的 `ImageLoadSource` 工厂和应用图片 loader。

#### 6.1.5 写法

```csharp
var source = new StreamImagePreviewSource(
    cancellationToken => repository.OpenImageAsync(imageId, cancellationToken),
    displayName: "invoice.png",
    contentType: "image/png",
    identity: imageId);

previewer.Source = source;
```

#### 6.1.6 写法

```csharp
var source = ImageLoadSource.FromStream(
    cancellationToken => repository.OpenImageAsync(imageId, cancellationToken),
    cacheKey: $"invoice:{imageId}",
    version: imageVersion,
    displayName: "invoice.png");

previewer.ItemsSource = [new ImagePreviewItem(source)];
```

流工厂每次调用必须返回新的可读流，loader 拥有并关闭每次返回的流。内容需要稳定的跨请求 identity 时，请同时提供
`cacheKey` 和 `version`。

### 将并发配置移至应用级

ImagePreviewer 不再提供 `MaxConcurrentLoads`。请在注册 AtomUI 时统一配置下载和解码并发：

```csharp
this.UseAtomUI(builder =>
{
    builder.UseImageLoading(options =>
    {
        options.MaxConcurrentDownloads = 4;
        options.MaxConcurrentDecodes = 4;
    });

    builder.UseDesktopControls();
});
```

该配置作用于整个应用，由 `AsyncImage`、Avatar、ImagePreviewer 和其他使用图片加载管线的控件共享。

### 更新自定义标题解析器

解析器现在通过只读引用接收 context。Context 携带完整的 `ImagePreviewItem`，自定义标题逻辑可以使用
`Item.Title`、`Item.Source.DisplayName` 或 `Item.Tag`。

#### 6.1.5 写法

```csharp
public sealed class PreviewTitleResolver : IImagePreviewTitleResolver
{
    public string? ResolveTitle(ImagePreviewTitleResolveContext context)
    {
        return context.Source.DisplayName;
    }
}
```

#### 6.1.6 写法

```csharp
public sealed class PreviewTitleResolver : IImagePreviewTitleResolver
{
    public string? ResolveTitle(in ImagePreviewTitleResolveContext context)
    {
        return context.Item.Title
               ?? context.Item.Source.DisplayName
               ?? $"Image {context.CurrentIndex + 1} of {context.Count}";
    }
}
```

## 输入继承关系迁移

6.1.5 中，`LineEdit` 继承 AtomUI 的具体 `TextBox`。6.1.6 中，`LineEdit`、`TextBox` 和 `TextArea` 成为
继承新公开基类 `AbstractTextInput` 的同级控件；该基类统一承载文本输入、校验、尺寸、状态、外观变体、清除按钮、
计数和 Form 反馈行为。

#### 6.1.5 写法

```csharp
using AtomUI.Desktop.Controls;

static void ConfigureAtomInput(TextBox input)
{
    input.IsAllowClear = true;
    input.SizeType = CustomizableSizeType.Large;
}

ConfigureAtomInput(new LineEdit());
```

#### 6.1.6 写法

```csharp
using AtomUI.Controls;
using AtomUI.Desktop.Controls;

static void ConfigureAtomInput(AbstractTextInput input)
{
    input.IsAllowClear = true;
    input.SizeType = CustomizableSizeType.Large;
    input.Status = InputControlStatus.Default;
}

ConfigureAtomInput(new LineEdit());
ConfigureAtomInput(new TextBox());
ConfigureAtomInput(new TextArea());
```

如果 helper 只需要 Avalonia 文本编辑 API，可接受 `Avalonia.Controls.TextBox`。需要 AtomUI 输入状态和 Form 集成的
自定义控件应继承 `AbstractTextInput`；明确要求 AtomUI `TextBox` 行为的代码不能再假设可传入 `LineEdit`。

## OTP 单元格迁移

`OtpLineEditCell` 在 6.1.6 中是内部模板实现。应用不得再实例化该类型、以 CLR 类型为目标编写样式、设置其原
`EffectiveStatus`/`SizeType`/`StyleVariant` 属性，或引用生成式单元格 Token API。请配置公开的
`OtpLineEdit`，其模板会把共享输入状态传递给单元格。

#### 6.1.5 写法

```xml
<UserControl.Styles>
    <Style Selector="atom|OtpLineEditCell">
        <Setter Property="SizeType" Value="Large" />
        <Setter Property="StyleVariant" Value="Filled" />
        <Setter Property="EffectiveStatus" Value="Warning" />
    </Style>
</UserControl.Styles>
```

#### 6.1.6 写法

```xml
<atom:OtpLineEdit
    Length="6"
    SizeType="Large"
    StyleVariant="Filled"
    Status="Warning" />
```

需要更深层视觉定制时，请为公开 `OtpLineEdit` 表面和已记录的公开属性编写样式，或提供完整的自定义
`OtpLineEdit` 模板。不要依赖内部单元格控件或内部输入框架类型。

## 重新构建兼容边界

Avatar 命名空间和程序集归属、生成式 Token 命名空间、ImagePreviewer source 模型、解析器签名、输入继承关系和
OTP 可见性均改变了二进制契约。请同步升级所有 AtomUI 包和 `AtomUI.Generator`，重新构建应用与主题程序集，
不要将 6.1.5 生成资产或控件程序集与 6.1.6 运行时混用。

# AtomUI 6.1.4 API 变更示例

本文档补充 `6.1.4` 相比 `6.1.3` 的破坏性 API 变更和迁移写法。正式版本条目见仓库根目录
`CHANGELOG.md` 和 `CHANGELOG.zh-CN.md`。

使用 SearchEdit 搜索事件、自定义本地化 Catalog、手工构造本地化 Descriptor 或自定义静态语言包的应用，
升级前必须完成本文迁移。

英文版本：[6.1.4 API Change Examples](6.1.4-api-changes.md)。

## 快速对照

| 范围 | 6.1.3 | 6.1.4 |
|---|---|---|
| SearchEdit 事件 | `SearchButtonClick` 和 `RoutedEventArgs` | `SearchRequested` 和 `SearchRequestedEventArgs` |
| SearchEdit Enter 行为 | 没有内置 Enter 搜索请求 | Enter 默认请求搜索，通过 `IsSearchOnEnterEnabled` 配置 |
| Catalog 版本 identity | `LanguageCatalogAttribute.ContractVersion` | 稳定 enum Key 和源文本 fingerprint |
| 运行时本地化 Descriptor | 构造函数和 Descriptor 携带 `ContractVersion` | 不再包含版本参数或属性 |
| 语言包契约校验 | `AtomUILanguageContractVersion` 和 `AtomUIRequireVerifiedLanguageContract` | 根据权威组件引用自动推导校验策略 |
| Localization 构建任务路径覆盖 | `AtomUILocalizationBuildTasksAssembly` | 所有构建能力共享 `AtomUIBuildTasksAssembly` |

## SearchEdit 请求迁移

### 以 `SearchRequested` 替代 `SearchButtonClick`

`SearchButtonClickEvent` 和 `SearchButtonClick` 已移除。替代事件统一表达搜索按钮或 Enter 键发起的搜索请求；
事件参数包含请求触发时的文本快照和触发来源。

#### 6.1.3 写法

```xml
<atom:SearchEdit
    Text="{Binding Query}"
    SearchButtonClick="HandleSearchButtonClick" />
```

```csharp
private void HandleSearchButtonClick(object? sender, RoutedEventArgs e)
{
    if (sender is SearchEdit searchEdit)
    {
        StartSearch(searchEdit.Text ?? string.Empty);
    }
}
```

#### 6.1.4 写法

```xml
<atom:SearchEdit
    Text="{Binding Query}"
    SearchRequested="HandleSearchRequested" />
```

```csharp
private void HandleSearchRequested(object? sender, SearchRequestedEventArgs e)
{
    StartSearch(e.Query, e.Trigger);
}

private void StartSearch(string query, SearchTriggerSource trigger)
{
    var source = trigger switch
    {
        SearchTriggerSource.Button => "button",
        SearchTriggerSource.EnterKey => "enter",
        _ => throw new ArgumentOutOfRangeException(nameof(trigger))
    };

    Search(query, source);
}
```

直接引用 RoutedEvent 字段的代码需要从 `SearchButtonClickEvent` 迁移到 `SearchRequestedEvent`。异步搜索应使用
`e.Query`，不要稍后再读取 `SearchEdit.Text`；`Query` 是请求时快照，输入内容在搜索期间变化不会改写该值。

### 保留仅点击按钮搜索的行为

Enter 现在默认在未处理的 `KeyUp` 上触发 `SearchRequested`。既有应用需要保留 6.1.3 仅点击按钮搜索的行为时，
将 `IsSearchOnEnterEnabled` 设为 `false`：

```xml
<atom:SearchEdit
    IsSearchOnEnterEnabled="False"
    SearchRequested="HandleSearchRequested" />
```

`IsOperating=true` 时，SearchEdit 会同时抑制按钮和 Enter 发起的请求。搜索执行期间仍应使用该属性阻止重复请求。

## Localization 契约迁移

### 移除 Catalog 契约版本

`LanguageCatalogAttribute.ContractVersion` 已移除。Catalog enum 成员名及对应 XLIFF `unit id` 是稳定 Key；
已发布 Key 只能在末尾追加，不得删除、重排、重命名或复用于其他语义。

#### 6.1.3 写法

```csharp
using AtomUI.Localization;

[LanguageCatalog(ContractVersion = 3)]
public enum AppLangResourceKind
{
    Title,
    Save
}
```

#### 6.1.4 写法

```csharp
using AtomUI.Localization;

[LanguageCatalog]
public enum AppLangResourceKind
{
    Title,
    Save
}
```

不要用自定义数字 identity 替代已移除的版本。兼容性现在根据 Catalog ID、稳定 Key、源文本、placeholder 和
生成式源文本 fingerprint 校验。

### 更新手工构造的 Descriptor

`LanguageCatalogDescriptor.ContractVersion` 和 `TranslationBundleDescriptor.ContractVersion` 已移除，
对应构造参数同时移除。

#### 6.1.3 写法

```csharp
var catalog = new LanguageCatalogDescriptor<AppLangResourceKind>(
    "Acme.App:Acme.AppLangResourceKind",
    3,
    [
        new LanguageCatalogUnitDescriptor("Title"),
        new LanguageCatalogUnitDescriptor("Save")
    ],
    static key => key switch
    {
        AppLangResourceKind.Title => 0,
        AppLangResourceKind.Save => 1,
        _ => -1
    });

var bundle = new TranslationBundleDescriptor(
    catalog.CatalogId,
    catalog.ContractVersion,
    LanguageTags.EnUS,
    TranslationSourceKind.ModuleBuiltIn,
    "Acme.App",
    ["Settings", "Save"]);
```

#### 6.1.4 写法

```csharp
var catalog = new LanguageCatalogDescriptor<AppLangResourceKind>(
    "Acme.App:Acme.AppLangResourceKind",
    [
        new LanguageCatalogUnitDescriptor("Title"),
        new LanguageCatalogUnitDescriptor("Save")
    ],
    static key => key switch
    {
        AppLangResourceKind.Title => 0,
        AppLangResourceKind.Save => 1,
        _ => -1
    });

var bundle = new TranslationBundleDescriptor(
    catalog.CatalogId,
    LanguageTags.EnUS,
    TranslationSourceKind.ModuleBuiltIn,
    "Acme.App",
    ["Settings", "Save"]);
```

大多数应用不应手工构造这些 Descriptor。请同步升级 AtomUI 包并重新生成 Catalog 和 Bundle 源码，不要修改
生成文件。

### 更新静态语言包项目

`AtomUILanguageContractVersion` 和 `AtomUIRequireVerifiedLanguageContract` 不再是有效的作者契约。
从项目属性和 `AtomUILanguage` item metadata 中移除它们。普通组件 `ProjectReference` 或仅作者期使用的组件
`PackageReference` 现在会自动提供权威 Catalog。

#### 6.1.3 写法

```xml
<PropertyGroup>
  <AtomUIBuildLanguagePackage>true</AtomUIBuildLanguagePackage>
  <AtomUILanguageTag>ja-JP</AtomUILanguageTag>
  <AtomUILanguageModuleId>Acme.Controls</AtomUILanguageModuleId>
  <AtomUILanguageContractVersion>3</AtomUILanguageContractVersion>
  <AtomUIRequireVerifiedLanguageContract>true</AtomUIRequireVerifiedLanguageContract>
</PropertyGroup>

<ItemGroup>
  <ProjectReference Include="../Acme.Controls/Acme.Controls.csproj" />
</ItemGroup>
```

#### 6.1.4 写法

```xml
<PropertyGroup>
  <AtomUIBuildLanguagePackage>true</AtomUIBuildLanguagePackage>
  <AtomUILanguageTag>ja-JP</AtomUILanguageTag>
  <AtomUILanguageModuleId>Acme.Controls</AtomUILanguageModuleId>
</PropertyGroup>

<ItemGroup>
  <ProjectReference Include="../Acme.Controls/Acme.Controls.csproj" />
</ItemGroup>
```

普通组件引用会自动要求完整契约校验。社区语言包作者期无法取得组件时，语言包保持 `Deferred`，消费应用在目标
模块激活后完成校验。不要在生成的包 props 中手工写入 `AtomUILanguageContractValidation`。

### 重命名自定义构建任务路径覆盖属性

普通 NuGet 消费项目不需要设置构建任务路径。自定义源码构建或测试宿主如果覆盖 Task DLL 位置，需要将
`AtomUILocalizationBuildTasksAssembly` 重命名为通用 `AtomUIBuildTasksAssembly` 属性。

#### 6.1.3 写法

```xml
<PropertyGroup>
  <AtomUILocalizationBuildTasksAssembly>$(RepoRoot)/tools/AtomUI.Build.Tasks.dll</AtomUILocalizationBuildTasksAssembly>
</PropertyGroup>
```

#### 6.1.4 写法

```xml
<PropertyGroup>
  <AtomUIBuildTasksAssembly>$(RepoRoot)/tools/AtomUI.Build.Tasks.dll</AtomUIBuildTasksAssembly>
</PropertyGroup>
```

Localization、Theme asset 和 linked registration 共用该属性，不要再为单个 AtomUI 构建能力设置不同的 Task
Assembly 路径。

### 重新构建兼容边界

Catalog 和 Bundle 构造签名已经变化，生成式包 metadata 也不再携带数字契约版本。组件包、Generator、应用和
静态语言包必须一起升级。请从当前权威 `en-US.xlf` 重新导出并构建全部语言包，不要将 6.1.3 本地化程序集或
生成式语言包资产与 6.1.4 运行时包混用。

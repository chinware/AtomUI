# AtomUIGallery pt-BR Translation Glossary

This glossary keeps repeated Gallery terminology stable. Product names, API names,
control type names, enum members, URLs, code snippets, and placeholders remain unchanged.

Gallery targets remain in XLIFF `translated` state until a Brazilian Portuguese reviewer
approves them. Reviewers promote accepted units to `reviewed` or `final`; build automation
must not promote draft translations automatically.

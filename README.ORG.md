# AtomUI

AtomUI provides Ant Design-style UI components for Avalonia and .NET desktop applications.

The project focuses on practical desktop development: predictable component behavior, consistent visual language, cross-platform support, and documentation that developers can actually use.

## What We Build

- **AtomUI OSS**  
  Open-source UI components for Avalonia desktop applications.

- **Design System for Desktop**  
  Components and theme conventions based on the Ant Design design language, adapted for desktop application scenarios.

- **Documentation and Examples**  
  Getting started guides, component usage, API references, examples, and FAQ content for developers.

- **Commercial Components**  
  Advanced components and support options for teams building production desktop software.

## Use Cases

AtomUI is designed for Avalonia-based desktop applications, including:

- Business and admin desktop clients
- Developer tools and database clients
- Cross-platform internal tools
- Enterprise applications that need a consistent UI system across Windows, macOS, and Linux

## Contributing

We welcome contributions from developers using Avalonia and .NET desktop technologies.

Useful contributions include:

- Bug reports with reproducible examples
- Component fixes and behavior improvements
- Documentation updates
- Example projects and usage notes
- API and component design discussions

Before opening a pull request, please check the contribution guide, coding style, and build instructions in the target repository.
